CAPITAL : PAPEETE ( PPT )

FRENCH POLYNESIA IS A FRENCH “OVERSEAS TERRITORY” AND CONSISTS OF 5 ARCHIPELAGOS WITH A TOTAL OF 130 ISLANDS.

1.                   SOCIETY ISLANDS :

a.      WINDWARD ISLANDS { MOOREA AND TAHITI }

b.      LEEWARD ISLANDS { BORA BORA, HUAHINE, MAUPITI, RAIATEA }

2.                   TUAMOTU ISLANDS { ANAA, HAO, MANIHI, RANGIRAO }

3.                   GAMBIER  ISLANDS { RIKITEA }

4.                   MARQUESAS ISLANDS { HIVA OA, NUKU HIVA, UA HAKA, UA POU }

5.                   AUSTRALES ISLANDS { RURUTU, TUBUAI }

INDIAN NATIONALS REQUIRE VISA FOR TRAVEL, VISA ISSUED BY DIPLOMATIC REPRESENTATIONS OF FRANCE. DOCUMENTS ARE REFERRED FOR VISA APPROVAL TO PAPEETE.
