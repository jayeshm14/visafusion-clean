# 15_Templates_Prompt_Library_Command_Catalog

# Purpose

Provide deterministic reusable templates, prompt patterns, command
catalog, and engineering artifacts for the VisaFusion modernization
program.

------------------------------------------------------------------------

# 1. Template Library

Every work item should have standardized templates for:

-   Specification
-   Architecture Decision Record (ADR)
-   API Design
-   Database Change
-   Migration Plan
-   Test Plan
-   Risk Register
-   Release Notes
-   Post-Implementation Review

------------------------------------------------------------------------

# 2. Specification Template

Minimum sections:

-   Identifier
-   Title
-   Objective
-   Business Context
-   Scope
-   Out of Scope
-   Functional Requirements
-   Business Rules
-   Non-functional Requirements
-   Acceptance Criteria
-   Risks
-   Dependencies
-   Traceability

------------------------------------------------------------------------

# 3. Prompt Library

Reusable prompt categories:

-   Legacy analysis
-   Architecture review
-   Database modernization
-   API generation
-   UI migration
-   Security review
-   Test generation
-   Documentation generation
-   Performance review
-   Code review

Prompts must reference approved specifications and must not invent
requirements.

------------------------------------------------------------------------

# 4. Command Catalog

Typical engineering commands:

-   Analyze legacy module
-   Generate specification
-   Update Knowledge Graph
-   Create ADR
-   Review architecture
-   Generate migration plan
-   Validate database
-   Produce API contracts
-   Generate regression tests
-   Build release notes

Commands are deterministic and require explicit inputs.

------------------------------------------------------------------------

# 5. Engineering Checklists

Each command should document:

-   Inputs
-   Preconditions
-   Outputs
-   Validation rules
-   Traceability updates
-   Risks

------------------------------------------------------------------------

# 6. Artifact Standards

All generated artifacts shall:

-   Be version controlled
-   Be machine-readable where practical
-   Include authorship metadata
-   Include revision history
-   Maintain consistent naming

------------------------------------------------------------------------

# 7. Naming Conventions

Examples:

Specifications: SPEC-XXXX

Architecture Decisions: ADR-XXXX

Database Scripts: DB-XXXX

Test Suites: TEST-XXXX

Migration Scripts: MIG-XXXX

------------------------------------------------------------------------

# 8. Release Package

Every release should include:

-   Updated specifications
-   Architecture documentation
-   ADRs
-   Database scripts
-   Source code
-   Test evidence
-   Deployment guide
-   Rollback guide
-   Release notes

------------------------------------------------------------------------

# 9. Governance

Before publishing any artifact verify:

-   Specification alignment
-   Traceability
-   Documentation quality
-   Security implications
-   Version information

------------------------------------------------------------------------

# 10. Definition of Done

The template and command library is complete only when:

-   Templates are standardized
-   Commands are documented
-   Prompt patterns are reusable
-   Artifacts are versioned
-   Governance requirements are satisfied

This document provides the deterministic template library and command
catalog supporting the VisaFusion modernization handbook.
